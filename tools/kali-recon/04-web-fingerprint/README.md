# Web fingerprinting

Script: `mywhatweb.sh`

Use this script only for local labs, your own assets, or explicitly authorized testing.

## Example

``bash
chmod +x mywhatweb.sh
./mywhatweb.sh example.com
``

## Safety

Do not run this against unauthorized public targets. Do not use it for password attacks, destructive activity, login bypass, or unauthorized data access.

# New Project 2

一个本地文件上传示例项目，同时保存 Web 安全学习笔记。

## 项目内容

- `server.js`：Node.js 本地文件上传服务。
- `public/`：前端页面资源。
- `docs/dvwa-burp-sqli-notes.md`：DVWA + Burp Suite SQL 注入学习笔记整理版。

## 本地运行

```bash
npm start
```

默认访问地址：

```text
http://localhost:3000
```

- [DVWA + Burp Suite SQL 注入学习笔记](docs/dvwa-burp-sqli-notes.md)

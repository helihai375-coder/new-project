## 程序功能

用户输入一组成绩，例如：

```text
85,90,72,60,45,100,88
```

程序会统计：

- 总人数
- 最高分
- 最低分
- 平均分
- 及格人数
- 不及格人数
- 优秀人数

如果输入了非数字或超出 0 到 100 的成绩，程序会提示错误并要求重新输入。

## 运行方式

```bash
python score_statistics.py
```

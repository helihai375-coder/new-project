# Code Library

Use this folder to store code you want to keep and reuse.

## Folders

- `snippets/` - short reusable examples.
- `projects/` - complete or semi-complete small projects.
- `notes/` - explanations, commands, links, and reminders.
- `templates/` - starter files for new work.

## Notes Included

- `notes/git-commands.md` - common Git commands.
- `notes/kali-common-commands.md` - common Kali Linux commands and their purposes.

## Suggested Naming

Use names that describe the purpose:

- Good: `parse-csv-file.py`
- Good: `express-basic-server.js`
- Avoid: `test1.js`

## Entry Template

When adding a new piece of code, include:

- What it does.
- How to run it.
- Any dependencies.
- Date or source, if useful.
